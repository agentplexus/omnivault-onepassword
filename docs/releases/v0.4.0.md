# Release Notes: v0.4.0

**Release Date:** 2026-05-24

Added auto-registration support for `op://` URI scheme via the new register package.

## Highlights

- Auto-registration support for `op://` URI scheme via register package
- Simplified setup with import-based provider registration

## New Features

### Auto-Registration Package

Import the register package for automatic provider registration:

```go
import _ "github.com/plexusone/omni-onepassword/omnivault/register"

// Now you can use op:// URIs directly
v, err := omnivault.VaultFromURI("op://MyVault")
```

This enables using `op://` URIs with `omnivault.VaultFromURI()` without manual provider setup.

## Changes

### Added

- `omnivault/register` package for automatic provider registration on import
- Support for `omnivault.VaultFromURI("op://MyVault")` without manual setup

### Dependencies

- Update `github.com/plexusone/omnivault` from v0.3.0 to v0.5.0
- Update `golang.org/x/sys` from v0.43.0 to v0.45.0

## Quick Start

### With Auto-Registration (New)

```go
package main

import (
    "context"
    "fmt"
    "log"

    "github.com/plexusone/omnivault"
    _ "github.com/plexusone/omni-onepassword/omnivault/register"
)

func main() {
    ctx := context.Background()

    // Use op:// URIs directly
    v, err := omnivault.VaultFromURI("op://MyVault")
    if err != nil {
        log.Fatal(err)
    }
    defer v.Close()

    secret, err := v.Get(ctx, "API Keys/github-token")
    if err != nil {
        log.Fatal(err)
    }
    fmt.Println("Token:", secret.Value)
}
```

### Direct Usage (Existing)

```go
package main

import (
    "context"
    "fmt"
    "log"

    op "github.com/plexusone/omni-onepassword/omnivault"
)

func main() {
    provider, err := op.NewFromEnv()
    if err != nil {
        log.Fatal(err)
    }
    defer provider.Close()

    ctx := context.Background()
    secret, err := provider.Get(ctx, "Private/API Keys/github-token")
    if err != nil {
        log.Fatal(err)
    }
    fmt.Println("Token:", secret.Value)
}
```

## Requirements

- Go 1.25 or later
- 1Password account with Service Account access
